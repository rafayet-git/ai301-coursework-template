# Playbook: Rafayet Hossain

## Response rules

- Open by acknowledging the maintainer's response, then state the result.
- Explain my reasoning only when it relates to the repository or its contribution guidelines.

## Staleness thresholds

- Quiet is normal until the maintainer's expected response time has passed. For rule PRs on mcp-audit that is 7 days.
- A nudge is on the table about 2 days after that expected time, so about day 9.

## Nudge etiquette

- One nudge only; it never repeats.
- No @-mentions.
- It must say something new, so I find what has changed since my last message before I write it.

## Walk-away criteria

- The issue is closed.
- The maintainer says no.
- The maintainer's next suggestion or commit is a significant change to what I proposed.
- I do not close my PR because of no response.
